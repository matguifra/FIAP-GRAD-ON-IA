## 🎯 Objetivo da Fase

Aplicar algoritmos de Machine Learning em problemas reais do agronegócio, abrangendo tanto regressão quanto classificação, com foco em:

- Desenvolver aplicações interativas com modelos preditivos
- Aplicar a metodologia CRISP-DM no ciclo completo de desenvolvimento
- Implementar e otimizar algoritmos de classificação com Scikit-learn
- Realizar pré-processamento e normalização de dados
- Avaliar modelos por meio de métricas e visualizações apropriadas

## 📖 Conteúdos Abordados

- Metodologia CRISP-DM
- Aprendizado supervisionado (regressão e classificação)
- Pré-processamento de dados e normalização (`StandardScaler`)
- Análise exploratória e detecção de outliers
- Implementação e otimização de hiperparâmetros
- Avaliação de modelos: matriz de confusão, acurácia e validação
- Desenvolvimento de aplicações web interativas com Streamlit
- Publicação de aplicações em nuvem (Streamlit Cloud)

## 📂 Projetos Desenvolvidos

### 📌 Projeto 1 — Estimador de Irrigação Agrícola

**Descrição:**

Aplicação web interativa desenvolvida em Streamlit que utiliza um modelo preditivo para estimar a quantidade de irrigação necessária para diferentes culturas agrícolas a partir de variáveis ambientais e climáticas. O projeto inclui uma página de exploração dos dados e outra dedicada à modelagem e avaliação do modelo, e está publicado em nuvem (Streamlit Cloud) para acesso público.

**Links do projeto:**

- 🌐 [App publicado no Streamlit Cloud](https://estimador-irrigacao.streamlit.app/)

- 🎥 [Vídeo — Modelagem e Avaliação](https://youtu.be/ggH5JufFH_M)

**Tecnologias utilizadas:**

- Python 3
- Streamlit (e Streamlit Cloud)
- Pandas e NumPy
- Scikit-learn
- Plotly, Matplotlib e Seaborn

**Principais aprendizados:**

- Desenvolvimento de aplicações web interativas para Machine Learning
- Estruturação de páginas para exploração de dados e modelagem

### 📌 Projeto 2 — Classificação Inteligente de Grãos de Trigo com Scikit-learn

**Descrição:**

Projeto de classificação supervisionada para identificar a variedade de grãos de trigo a partir de características físicas (Área, Perímetro, Compactação e Largura/Comprimento do Núcleo) utilizando o Seeds Dataset do repositório UCI. O desenvolvimento seguiu a metodologia CRISP-DM, com etapas de análise e pré-processamento, implementação de diferentes algoritmos, otimização de hiperparâmetros e avaliação dos modelos por meio de matriz de confusão e métricas de acurácia.

**Tecnologias utilizadas:**

- Python 3
- Pandas e NumPy
- Scikit-learn (StandardScaler e classificadores)
- Matplotlib e Seaborn
- Jupyter Notebook / Google Colab

**Principais aprendizados:**

- Aplicação prática da metodologia CRISP-DM
- Pré-processamento, normalização e detecção de outliers
- Implementação e comparação de diferentes algoritmos de classificação
- Otimização de hiperparâmetros para maximizar o desempenho
- Avaliação de modelos com matriz de confusão e métricas técnicas
- Conexão entre resultados técnicos e ganhos de negócio no agronegócio
