## 🎯 Objetivo da Fase

Apresentar os fundamentos da Inteligência Artificial e suas aplicações práticas no agronegócio, com foco em:

- Desenvolver os primeiros programas em Python aplicados à Agricultura Digital
- Aplicar estatística descritiva com a linguagem R
- Construir e treinar um primeiro modelo de Visão Computacional
- Compreender o ciclo básico de coleta, treinamento e avaliação de modelos de IA
- Explorar plataformas no-code para introdução ao Machine Learning

## 📖 Conteúdos Abordados

- Introdução à programação em Python
- Estruturas de dados (vetores) e operações CRUD em memória

- Introdução à Visão Computacional
- Coleta e organização de datasets de imagens

- Uso de plataformas no-code para Machine Learning (Teachable Machine)

## 📂 Projetos Desenvolvidos

### 📌 Projeto 1 — FarmTech Solutions: Aplicação para Agricultura Digital

**Descrição:**

Projeto introdutório desenvolvido para a startup fictícia FarmTech Solutions, com o objetivo de apoiar uma fazenda na migração para a Agricultura Digital. A aplicação em Python suporta duas culturas (soja e milho) e calcula automaticamente a área de plantio, a quantidade de insumos e o volume de água necessário para o manejo, a partir das dimensões informadas pelo usuário e com base em dados da EMBRAPA. Inclui um menu interativo com operações de entrada, consulta, atualização e remoção dos dados das lavouras armazenados em vetores. Como complemento, foi desenvolvido um script em R para gerar estatísticas descritivas (média, mediana e desvio padrão) sobre os dados gerados.

**Tecnologias utilizadas:**

- Python 3
- R
- Dados públicos da EMBRAPA

**Principais aprendizados:**

- Primeiros passos em programação Python
- Implementação de operações CRUD com vetores
- Construção de menus interativos no terminal
- Aplicação de cálculos do agronegócio em código
- Introdução à linguagem R para estatística descritiva
- Integração de dois ambientes (Python e R) em um mesmo fluxo de trabalho

### 📌 Projeto 2 — IA e seu mundo de possibilidades: Classificação de Imagens com Teachable Machine

**Descrição:**

Projeto introdutório à Visão Computacional e Machine Learning, com o objetivo de desenvolver um modelo capaz de detectar e classificar diferentes tipos de utensílios de cozinha a partir de imagens. O modelo foi treinado utilizando a plataforma Teachable Machine do Google, a partir de conjuntos de imagens categorizadas. Foram realizados experimentos de ajuste de hiperparâmetros (épocas, tamanho do lote e taxa de aprendizado), com avaliação da acurácia do modelo e justificativas técnicas documentadas em relatório.

**Tecnologias utilizadas:**

- Teachable Machine (Google)
- Datasets de imagens categorizadas

**Principais aprendizados:**

- Compreensão dos conceitos fundamentais de Visão Computacional
- Coleta e organização de datasets de imagens
- Treinamento e avaliação de modelos de classificação
- Ajuste de hiperparâmetros (épocas, batch size e learning rate)
- Análise de acurácia e qualidade da classificação
- Documentação técnica de experimentos de Machine Learning
