## 📜 Descrição

O objetivo deste projeto foi desenvolver um modelo de Inteligência Artificial usando o Teachable Machine do Google para detectar e classificar automaticamente diferentes tipos de utensílios de cozinha a partir de imagens. A ideia central foi utilizar conceitos de visão computacional e aprendizado de máquina para construir um modelo focado na identificação visual de objetos domésticos, avaliando sua precisão e qualidade de classificação.

Para isso, coletamos conjuntos de dados com fotos de utensílios categorizadas, para testar e treinar a rede através de ajustes nos parâmetros (épocas, tamanho do lote e taxa de aprendizado). O resultado das análises descritivas, com informações de desempenho e justificativas, está documentado em relatório.

## 📁 Estrutura de pastas

- <b>project.tm</b>: Arquivo salvo do modelo gerado no Teachable Machine; contém as classes de imagens e as configurações do modelo.
- <b>relatorio.pdf</b>: Documento detalhado sobre a metodologia, as taxas de acurácia, etapas do modelo e análise de resultados.
- <b>README.md</b>: Arquivo que serve como guia e explicação geral sobre o projeto.

## 🔧 Como executar

**Pré-requisitos:**

- Navegador web compatível.
- Acesso ao Teachable Machine (Google).
- Um leitor de PDF (para ler o relatório).

**Passo a passo:**

1. Leia o arquivo `relatorio.pdf` para se contextualizar e compreender todo o andamento do experimento e entender os números resultantes.
2. Acesse a plataforma [Teachable Machine](https://teachablemachine.withgoogle.com/) e vá em "Classificação de Imagem" -> "Abrir um arquivo ou projeto existente".
3. Faça o upload do arquivo `project.tm` encontrado nesta pasta.
4. Teste novas imagens nas categorias treinadas, utilizando sua webcam ou fazendo o upload direto ao sistema aberto no navegador para ver as probabilidades estimadas pela IA.
