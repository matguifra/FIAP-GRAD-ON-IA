## 🎯 Objetivo da Fase

Aplicar conceitos de Banco de Dados Relacional e os primeiros algoritmos de Machine Learning em problemas reais do agronegócio, com foco em:

- Estruturar tabelas relacionais para armazenar dados de sensores agrícolas
- Importar dados externos e executar consultas SQL analíticas
- Construir dashboards interativos para visualização dos dados coletados
- Desenvolver os primeiros modelos preditivos de Machine Learning
- Comparar diferentes algoritmos de classificação para recomendação de cultivos

## 📖 Conteúdos Abordados

- Modelagem relacional e estruturação de tabelas no Oracle
- Linguagem SQL: DDL, DML e consultas analíticas (SELECT, WHERE, ORDER BY, AVG, MAX, MIN)
- Importação de dados a partir de arquivos CSV
- Análise exploratória de dados (EDA)
- Desenvolvimento de dashboards interativos em Python
- Introdução ao Machine Learning supervisionado
- Construção e comparação de modelos de classificação
- Métricas de avaliação para problemas de classificação

## 📂 Projetos Desenvolvidos

### 📌 Projeto 1 — FarmTech Solutions: Banco de Dados Oracle e Análise de Sensores

**Descrição:**

Projeto desenvolvido para a FarmTech Solutions com o objetivo de armazenar e analisar as informações coletadas pelos sensores agrícolas em um banco de dados Oracle. Foi criada a tabela `SENSORES_FARMTECH` para receber as leituras simuladas (pH do solo, umidade, temperatura, NPK e status da bomba de irrigação), seguida da importação do arquivo CSV e da execução de consultas SQL para análise dos dados. Além da entrega principal, o projeto inclui dois módulos extras: um dashboard interativo em Python para visualização das leituras e uma introdução ao Machine Learning aplicado ao agro.

**Links do projeto:**

- 🎥 [Vídeo — Banco de Dados Oracle](https://youtu.be/Txpuv0JD0wU)
- 🎥 [Vídeo — Ir Além 1: Dashboard em Python](https://youtu.be/J9iB4t9So8U)
- 🎥 [Vídeo — Ir Além 2: Machine Learning no Agro](https://youtu.be/pic7SCPDPn0)

**Tecnologias utilizadas:**

- Oracle Database e Oracle SQL Developer
- SQL (DDL e DML)
- Python 3 (dashboard e Machine Learning)
- Pandas e NumPy

**Principais aprendizados:**

- Modelagem e criação de tabelas relacionais para séries temporais
- Importação de dados via assistente do Oracle SQL Developer
- Construção de consultas SQL analíticas com filtros, ordenação e agregações
- Interpretação de resultados a partir de regras de automação (irrigação)
- Construção de dashboards interativos para visualização de dados
- Primeiros passos no desenvolvimento de modelos preditivos

### 📌 Projeto 2 — A Primeira Técnica de Aprendizado de Máquina

**Descrição:**

Projeto introdutório de Machine Learning supervisionado, com o objetivo de recomendar o melhor cultivo agrícola para plantio a partir de características do solo (Nitrogênio, Fósforo, Potássio e pH) e do clima (temperatura, umidade e precipitação). O desenvolvimento foi dividido em duas grandes etapas: análise exploratória descritiva, com geração de insights e visualizações sobre os cenários ideais de cada cultivo, e modelagem preditiva, com o treinamento e comparação de cinco algoritmos diferentes de classificação avaliados por métricas adequadas ao problema.

**Tecnologias utilizadas:**

- Python 3
- Pandas e NumPy
- Matplotlib e Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

**Principais aprendizados:**

- Análise exploratória aplicada a dados agrícolas
- Construção de um pipeline introdutório de Machine Learning
- Implementação e comparação de cinco algoritmos de classificação
- Avaliação de modelos com métricas específicas para classificação
- Tradução de resultados técnicos em insights de negócio para o agronegócio
