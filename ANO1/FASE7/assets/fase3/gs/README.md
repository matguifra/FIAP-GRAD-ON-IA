## 📜 Descrição

Este projeto foi desenvolvido para a **Global Solutions 2025 - 2º semestre**, com a proposta de criar um **MVP funcional** utilizando conceitos de **Inteligência Artificial**, **Machine Learning**, coleta de dados, tratamento de dados e análise exploratória.

A solução apresentada utiliza uma base de dados em CSV e um notebook Jupyter para desenvolver um modelo relacionado à previsão/análise de burnout.

O objetivo foi demonstrar como técnicas de Ciência de Dados e Machine Learning podem apoiar a identificação de padrões e riscos associados ao esgotamento profissional.

---

## 🎯 Objetivo

O objetivo principal da solução foi construir um MVP capaz de:

- carregar uma base de dados estruturada;
- realizar tratamento e análise dos dados;
- explorar padrões relacionados ao burnout;
- aplicar técnicas de Machine Learning;
- documentar os resultados em um PDF;
- demonstrar a solução de forma prática em vídeo.

---

## 🧠 Contexto da Solução

A Global Solution propôs o desenvolvimento de uma solução prática com aplicação de IA e Machine Learning.

Neste projeto, o grupo trabalhou com uma base de dados voltada à análise de fatores relacionados ao burnout, buscando transformar dados em informações úteis para tomada de decisão, prevenção e acompanhamento.

## 🔧 Como Executar

### Pré-requisitos

- Python 3 instalado;
- Jupyter Notebook, JupyterLab, Google Colab ou VS Code com suporte a notebooks;
- Bibliotecas de análise de dados usadas no notebook.

### Passo a passo

1. Clone este repositório em sua máquina.

2. Acesse a pasta da Global Solution:

```bash
cd assets/fase3/gs
```

3. Abra o notebook:

```text
burnout_predictor.ipynb
```

4. Execute as células em ordem para visualizar o tratamento dos dados, análises e resultados do modelo.

5. Consulte o PDF para entender a proposta completa da solução:

```text
global-solutions-burnout-predictor.pdf
```
